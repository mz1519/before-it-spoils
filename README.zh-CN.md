# Before It Spoils

[English](README.md) | [简体中文](README.zh-CN.md)

一款结合食材保鲜、烹饪与虚拟宠物养成的 Unity 2D 游戏原型。将食材放入冰箱，在它们变质之前做成料理，陪伴宠物成长。

作者：**刘木子（Muzi Liu）**。

## 项目构想

Before It Spoils 通过食材外观的变化，以及不同新鲜程度对烹饪结果的影响，让玩家感受到时间的流逝。照顾宠物的过程，也为关注冰箱中剩余的食材提供了动力。

## 主要功能

- **三个相互连接的页面：** 通过横向滑动，在食材选择、冰箱和宠物页面之间切换。
- **拖拽存放：** 将食材放入冰箱，并调整它们的位置。
- **可视化新鲜度：** 食材依次经历新鲜、不新鲜和腐烂三个阶段。
- **双食材烹饪：** 根据两份食材的类别与新鲜程度生成不同料理。
- **宠物成长：** 料理影响成长值与心情值；成长值达到阈值后，宠物升级并改变外观。
- **动画与音效反馈：** 包含烹饪、料理展示、喂食动画及交互音效。

目前包含八种食材：牛肉、鸡肉、鱼、鸡蛋、牛奶、菠菜、番茄和蓝莓。食材数据使用 Unity ScriptableObject 配置。

## 打开项目

### 环境要求

- Unity Hub 及 **Unity Editor 6000.4.8f1**，版本以 `ProjectSettings/ProjectVersion.txt` 为准。
- 首次打开克隆项目时，需要联网安装依赖包。

### 操作步骤

1. 克隆仓库：

   ```bash
   git clone https://github.com/mz1519/before-it-spoils.git
   ```

2. 在 Unity Hub 中，将克隆后的 `before-it-spoils` 文件夹添加为现有项目。
3. 使用 Unity **6000.4.8f1** 打开，等待资源导入和依赖包解析完成。
4. 打开 `Assets/Scenes/SampleScene.unity`。
5. 点击 **Play**，在 **Game** 视图中体验游戏。

项目清单声明了 Unity AI Assistant `2.9.0-pre.2` 依赖，但其本地嵌入副本已被 Git 忽略。新克隆的项目需要通过 Package Manager 解析此依赖；目前尚未验证该具体版本是否可下载。如果 Unity 提示依赖包错误，请先在 Package Manager 中检查 Assistant 依赖。

## 玩法与操作

| 操作 | 方法 |
| --- | --- |
| 切换页面 | 在页面背景上按住鼠标并横向拖动。 |
| 存放食材 | 从食材页面拖动食材至屏幕右侧边缘，切换到冰箱页面后松开。 |
| 调整食材位置 | 在冰箱内拖动已存放的食材。 |
| 将食材送至烹饪区 | 长按冰箱内的食材约一秒，将其移至宠物页面的空闲食材槽。 |
| 烹饪料理 | 从宠物页面的食材槽中，将两份食材拖入锅中。 |
| 喂食宠物 | 等待成品料理展示完成；当前场景会自动喂食。 |

### 新鲜度与食谱

原型使用加速计时：食材放入冰箱后，默认保持新鲜 **5 秒**，随后进入持续 **5 秒**的不新鲜阶段，最后腐烂。计时由 `FoodTimer` 控制；食材数据中的 `staleDays` 和 `rottenDays` 字段目前没有参与倒计时计算。

部分食谱示例：

| 食材组合 | 料理 |
| --- | --- |
| 肉类或鱼类 + 蔬菜 | 炖菜 |
| 鸡蛋 + 蔬菜 | 蔬菜蛋汤 |
| 鸡蛋 + 牛奶 | 奶香鸡蛋布丁 |
| 水果 + 牛奶 | 奶昔 |
| 两份蔬菜 | 田园沙拉 |

使用不新鲜的食材，会使料理提供的成长值和心情值减半。只要包含腐烂食材，就会生成失败料理，并降低宠物的成长值与心情值。

## 项目结构

| 路径 | 内容 |
| --- | --- |
| `Assets/Scenes/` | 主游戏场景。 |
| `Assets/Script/` | 交互、新鲜度、烹饪、宠物、动画与音效脚本。 |
| `Assets/FoodData/` | 食材的 ScriptableObject 数据。 |
| `Assets/FoodImage/` | 食材图片及不同新鲜阶段的图片。 |
| `Assets/Prefabs/` | 可复用的游戏对象。 |
| `Assets/Animation/`、`Assets/Pet/`、`Assets/Audio/` | 动画、宠物及音频资源。 |
| `Packages/manifest.json` | 依赖包配置。 |
| `ProjectSettings/` | Unity 项目设置。 |

核心系统包括：负责新鲜度的 `FoodTimer`、负责食谱的 `CookingPotManager`、负责宠物成长的 `PetStatsManager`，以及负责页面切换的 `PageSwiper`。

## 原型说明

- 游戏进度保存在内存中；当前玩法脚本尚未实现存档与读档系统。
- 计时、奖励和界面行为均为原型参数，可通过脚本或 Inspector 调整。
- 本仓库保存 Unity 源项目；生成的构建文件、缓存、日志和本地编辑器设置通过 `.gitignore` 排除。
- 修改资源时，请保留对应的 Unity `.meta` 文件，它们用于维持场景和预制体中的资源引用。
